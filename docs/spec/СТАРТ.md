## Ключевые правила, которые нельзя нарушить
1. **Продукт рождается пустым.** Никаких воронок, целей, цен, скриптов и слова «аудит»
   в коде. Всё «агентское» на макетах — данные первой команды, введённые через интерфейс.
2. **Воронка — сущность:** имя, путь касаний, целевое действие (свободный текст + цена
   опционально), скрипт, шаблоны, правило недозвонов. Зелёная кнопка селза рендерится
   из настройки воронки его лида.
3. **Один код — два инстанса**: внутренний со своей базой + публичный позже. Форков нет.
4. **Роли:** Владелец → Админ → Менеджер → Селз. Селз не видит сумм и парсинга.
   Права проверяются на сервере, а не только в интерфейсе.
5. **Стиль-эталон:** фон #FAFAF7, поверхности #FFFFFF, границы #E9E6DE, текст #1E1B16 /
   #5C574B / #8A8578, акцент #1E6B4F, внимание #9A6B12, проблема #A84632, шрифт Manrope.
   Один экран — одно главное действие. Роль определяет экран: недоступное не рендерится.
6. **Метка «скоро» на макете** = функция заложена, в этой волне не реализуется.
